# 훈련관앱 — 캘린더·청소·리딩표·기도제목·마음의 편지

2026-10-12 제작. 기도제목보드(`신앙\5_기도제목\기도제목보드`)를 훈련관 멤버용 통합 앱으로 넓힌 것이다.
링크 하나로 들어가서 탭 5개를 같이 쓴다. Firebase 프로젝트는 기도제목보드와 같은 `prayer-requests-9d290`.

## 탭

| 탭 | 하는 일 | 데이터 위치 (Firestore) |
|---|---|---|
| 캘린더 | 식번(매일, 목요일 쉼, 토요일은 별도 순번)·타임키퍼(매주) 자동 순번. 설정에서 "이번 달 첫 순서" 지정, 칸을 눌러 그날만 바꾸기 | `boards/{id}/calendar/settings` |
| 청소 | 구역 추가·삭제, 구역마다 2명 고르기. **전부 손으로** (랜덤 없음) | `boards/{id}` 의 `cleaning` 필드 |
| 리딩표 | 날짜마다 읽은 장수. 월 합계 + 월별 합산·누적 표 (매달 시상용) | `boards/{id}/reading/{YYYY-MM}` |
| 기도제목 | 기도제목보드 그대로 (카톡 복사, 주차 보관, md 저장) | `boards/{id}/members`, `archives` |
| 편지 | 익명. 멤버 전원이 본다. 지우기 없음 | `boards/{id}/letters` |

**멤버 목록은 기도제목 탭의 형제 목록 하나뿐이다.** 청소·리딩표·내 이름 고르기 모두 거기서 가져온다.
리딩표에 내 줄을 적으려면 오른쪽 위 **내 이름**을 한 번 고른다 (그 기기에만 저장).

기도제목보드와 같다. **링크를 아는 사람 누구나** 읽고 고친다 (익명 로그인 + 24자 무작위 id).

## 2026-10-12 판단 기록

- 기도제목보드를 새로 짜지 않고 `boards/{id}`를 그대로 뿌리로 썼다. 기존 데이터를 옮길 필요가 없고, 규칙도 한 줄만 넓히면 돼서.
- 캘린더는 찬영이 준 `meal-calendar.html`의 순번 계산 로직(월 경계에서 이어받기, 목·토 제외, 토요일 별도)만 가져왔다.
  처음엔 화면까지 통째로 옮겼는데 "메뉴 빼고 디자인 통일, 딱 심플하게"라고 해서 같은 날 다시 만들었다.
  메뉴·메모·엑셀 가져오기·인쇄·PWA 를 뺐고, 이름은 직접 치지 않고 기도제목 탭 형제 목록에서 고른다.
  바꾸는 방법은 두 가지: 설정의 "이번 달 첫 순서"(순번 자체를 옮김), 칸 누르기(그날·그 주만 바꿈, 주황색으로 표시).
- 청소 짝은 찬영이 "무조건 수동, 랜덤 ×"라고 해서 섞기 버튼을 넣지 않았다. 주차 개념도 넣지 않았다 (지금 배정 하나만).
  주차별 기록이 필요해지면 그때 추가한다.
- 리딩표는 "매달 장수 기준으로 시상"이라 해서 월 합계 열 + 월별 합산·누적 표(누적 많은 순)를 넣었다.
- 편지에 지우기를 안 넣은 이유: 익명이라 누구 글인지 알 수 없으니 지우기를 열면 아무나 남의 글을 지울 수 있다.
- 테스트는 로컬 서버(127.0.0.1)에서 다섯 탭 렌더링·탭 전환·달력 계산까지 확인했다.
  Firestore 쓰기는 규칙 게시 전이라 실제로 확인하지 못했다.
