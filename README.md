## 2026-10-12 판단 기록

- 기도제목보드를 새로 짜지 않고 `boards/{id}`를 그대로 뿌리로 썼다. 기존 데이터를 옮길 필요가 없고, 규칙도 한 줄만 넓히면 돼서.
- 캘린더는 찬영이 준 `meal-calendar.html`의 순번 계산 로직(월 경계에서 이어받기, 목·토 제외, 토요일 별도)만 가져왔다.
  처음엔 화면까지 통째로 옮겼는데 "메뉴 빼고 디자인 통일, 딱 심플하게"라고 해서 같은 날 다시 만들었다.
  메뉴·메모·엑셀 가져오기·인쇄·PWA 를 뺐고, 이름은 직접 치지 않고 기도제목 탭 형제 목록에서 고른다.
  바꾸는 방법은 두 가지: 설정의 "이번 달 첫 순서"(순번 자체를 옮김), 칸 누르기(그날·그 주만 바꿈, 주황색으로 표시).
- 청소 짝은 찬영이 "무조건 수동, 랜덤 ×"라고 해서 섞기 버튼을 넣지 않았다. 주차 개념도 넣지 않았다 (지금 배정 하나만).
  주차별 기록이 필요해지면 그때 추가한다.
- 리딩표는 "매달 장수 기준으로 시상"이라 해서 월 합계 열 + 월별 합산·누적 표(누적 많은 순)를 넣었다.
- 편지에 지우기를 처음엔 안 넣었다(익명이라 아무나 남의 글을 지울 수 있어서). 10-25에 멤버 의견으로 넣되 아래 방식으로.
- 테스트는 로컬 서버(127.0.0.1)에서 다섯 탭 렌더링·탭 전환·달력 계산까지 확인했다.
  Firestore 쓰기는 규칙 게시 전이라 실제로 확인하지 못했다.

## 2026-10-25 암송 탭 추가

- 암송카드앱(50만 자 단일 파일)을 이 파일에 복사해 넣지 않고 **iframe으로 띄웠다.** 두 앱이 같은 주소(colze5812-dotcom.github.io)라 규칙 변경 없이 된다.
- 암송카드앱 쪽에 "훈련관 모드"를 넣었다: 주소에 `?board=<보드id>&me=<멤버id>&name=<이름>`이 붙으면 동기화 코드 대신
  `boards/<보드id>/bible/<멤버id>` 아래에 답변·메모를 저장하고, 외운 구절(`memorized`)도 문서에 통째로 올린다.
  처음 열 때 이 기기에 있던 답변·외운 구절은 그 자리로 올라간다(클라우드와 합침).
- 암송 탭 위의 진도표는 그 문서의 `memCount / total`을 읽는다. 기록이 없으면 `-`.
- 내 이름을 안 골랐으면 iframe 대신 "내 이름 고르기" 안내만 보인다.
- 테스트: 로컬 Chrome(127.0.0.1)이 이날은 막혀 있어서 헤드리스 Chrome으로 DOM만 확인했다. 암송카드앱 훈련관 모드 표시(🏠 이름)와 두 앱의 문법·오류 없음까지.
  실제 저장은 보드에서 직접 써 보며 확인해야 한다.

## 2026-10-25 암송·공부·게임 탭 · 편지 지우기

- 처음엔 암송카드앱을 iframe으로 띄웠는데, 찬영이 "디자인 양식까지 통일하고 암송·공부·게임을 따로 나누라"고 해서 같은 날 다시 만들었다.
  암송카드앱(`신앙_암송\암송카드앱`)의 **데이터만 `bible-data.js`로 뽑고 화면은 이 앱 디자인으로 새로 그렸다.** iframe은 없다.
  암송카드앱 자체는 그대로 두었고(따로 쓸 수 있음), 거기 넣었던 "훈련관 모드"는 이제 쓰이지 않는다.
- 기록은 `boards/{id}/bible/{memberId}`에 둔다. 암송·공부는 **내 이름**을 골라야 저장되고, 게임은 이름 없이도 된다.
- 같은 주소라 암송카드앱이 이 브라우저에 남긴 기록(localStorage `nav_*`)을 처음 한 번 내 자리로 올린다(외운 구절은 합집합, 답변은 없는 것만).
- 공부 탭은 적는 즉시 저장(0.7초 뒤). 다른 기기에서 바뀐 답은 지금 적고 있는 칸만 빼고 바로 반영된다.
- **편지 지우기**: 쓸 때 그 기기의 무작위 표식(`hq_letter_token`, localStorage)을 글에 같이 저장하고, 표식이 같은 글에만 "지우기"가 보인다.
  표식은 이름과 무관해서 익명은 그대로다. 기기를 바꾸거나 브라우저 데이터를 지우면 자기 글도 못 지운다. 두 번 눌러야 지워진다. 이전 글(표식 없음)은 못 지운다.
- 탭이 8개라 탭 줄은 좁은 화면에서 옆으로 밀린다.
- 테스트: 이날 헤드리스 Chrome에서 Firebase 로그인이 안 끝나서, Firebase를 가짜로 바꾼 사본으로 세 탭의 모든 동작(카드 뒤집기·외움·과 열기·답 입력·게임 4종)을 자동 클릭으로 확인했다. 실제 Firestore 저장은 보드에서 써 보며 확인해야 한다.
